# Íconos

Set único para toda la web: **Lucide** (lucide-static 1.52.0, licencia ISC, ver `LICENSE-lucide.txt`).
Retícula de 24 px, sin relleno, puntas y uniones redondas. En la interfaz se usan con trazo 1,75.

- Se copian como SVG sueltos; en el HTML se pegan en línea (para heredar `currentColor`) o se cargan con `<img>` cuando el color no cambia.
- `strawberry.svg` es propio de YoguraSo (Lucide no trae fresa): misma retícula y mismo trazo para que no desentone.
- No mezclar con Font Awesome en piezas nuevas. Font Awesome sigue cargado solo por las secciones que aún no se migraron.
